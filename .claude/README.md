# .claude — Claude Code Playbook

This folder contains helper docs tailored to Claude Code usage (environment, run/build commands, prompts, UI tips,
testing, and strategy). For the canonical engineering guide (architecture, plugin conventions, ADB command pattern,
logging, and the full Feature Design Checklist), see the root `AGENTS.md`.

Quick links:

- Claude-specific guidance: `CLAUDE.md`
- Local setup and commands: `.claude/DEVELOPMENT.md`

- Test guidance: `.claude/TESTING.md`
- Prompts/snippets: `.claude/PROMPTS.md`
- Execution strategy and rules: `.claude/STRATEGY.md`
