# Main structure

## Definition

The application should provide a fixed strucuture that will enable user to switch between features. This main structure is composed by:

### Plugin selector

All available plugins should be presented allowing the user to switch between them. It will also show the one currently selected.

### Actual device (Selector)

Shows the currently selected device. It should also provide a way to change the current one. When the app start, it automatically selects the device if there's only one available

### Companion status

Shows if the companion is connected, connecting or not available

### Status 

It's said of a structure used to present messages to the user be it an error or something informative. It's not required to be always visible, only when a message needs to be displayed to our user.
